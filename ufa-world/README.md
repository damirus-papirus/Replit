# UFA: REAL CITY — Minecraft Bedrock 1.20.80

Проект сборки карты Уфы по данным OpenStreetMap.

## Что делает сборка

- Загружает геоданные OSM для заданной области Уфы через Overpass.
- Преобразует здания, дороги, воду, зелёные зоны и точки интереса в блоки Minecraft.
- Использует масштаб `1.0` (1 метр реальности = 1 блок Minecraft).
- Создаёт Bedrock-мир и упаковывает его в `.mcworld`.
- Публикует архив как GitHub Actions artifact.

## Запуск

1. Открой вкладку **Actions** репозитория.
2. Выбери **Build UFA REAL CITY**.
3. Нажми **Run workflow**.
4. Оставь значения по умолчанию для первой сборки.
5. После завершения открой запуск и скачай artifact `UFA-REAL-CITY-Bedrock`.
6. Распаковывать архив artifact не нужно вручную: внутри будет файл `UFA-REAL-CITY.mcworld`. Открой его на Android и выбери Minecraft.

## Параметры первой сборки

- BBox: `54.65,55.78,55.10,56.20` — прямоугольная область вокруг городской территории Уфы; это не точная административная граница.
- Scale: `1.0`.
- Spawn: центр Уфы, приблизительно `54.735,55.958`.
- Edition: Bedrock.
- Название мира: `UFA REAL CITY`.

BBox можно изменить в форме запуска workflow. Для очень большой области Overpass может ограничить запрос; в таком случае нужно будет собирать соседние фрагменты отдельно.

## Важные ограничения

Это первая автоматическая географическая версия, а не ручная реконструкция каждого фасада. Геометрия и наличие объектов зависят от полноты OpenStreetMap. Высота зданий берётся из доступных OSM-тегов, а если данных недостаточно — используется высота по умолчанию генератора. Интерьеры обычных зданий не моделируются.

Совместимость целевая: Minecraft Bedrock 1.20.80. Генератор записывает Bedrock LevelDB; окончательную совместимость конкретного архива нужно проверить импортом в игре.
